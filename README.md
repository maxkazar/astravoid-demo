# AstraVoid demo

AstraVoid is a 4X space strategy game played through a retro CRT
terminal: boot the console, pick a race and lead your empire across the galaxy.
This is a small demo: a short slice of the game, not the full release.
This repository holds only the compiled browser demo build; the source is not published.

**[▶ Play now: maxkazar.github.io/astravoid-demo](https://maxkazar.github.io/astravoid-demo/)**

No install needed: it runs in any modern desktop browser.
Analytics are optional and loaded only with consent, see the [privacy notice](https://maxkazar.github.io/astravoid-demo/privacy.html).
